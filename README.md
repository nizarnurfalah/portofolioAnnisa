# Portofolio Profesional — Annisa Haura Salshabira, S.Tr.Keb

Website portofolio profesional untuk **Annisa Haura Salshabira**, lulusan Sarjana Terapan Kebidanan (Pendidikan Bidan Jalur Langsung) dari **Fakultas Kedokteran Universitas Padjadjaran (UNPAD)**.

## 🩺 Profil Singkat
- **Profesi:** Sarjana Terapan Kebidanan (Midwife)
- **Fokus:** Asuhan Kesehatan Ibu, Bayi Baru Lahir & Anak | Kesehatan Komunitas | Administrasi Kesehatan
- **Institusi:** Universitas Padjadjaran
- **HAKI Kemenkumham RI:** Pemegang resmi Hak Cipta Surat Pencatatan No. 000643844 (*Buku Saku MP-ASI*)

## 💻 Tech Stack
- **Framework:** Next.js 16 (App Router & Turbopack)
- **UI & Styling:** Tailwind CSS v4, Modern Healthcare Rose/Pink Palette
- **Bahasa:** TypeScript
- **Animasi:** AOS (Animate On Scroll) & CSS Animations

## 🚀 Menjalankan Secara Lokal

```bash
npm install
npm run dev
```

Buka [http://localhost:3000](http://localhost:3000) di browser.

## 📦 Build Produksi

```bash
npm run build
npm run start
```
